# 小小修理铺：成长与章节设计

## 核心体验

接诊 → 读症状 → 安全准备 → 打开设备 → 观察 / 测量 → 形成证据 → 处理故障 → 复装 → 验证 → 知识小测 → 交付 → 赚维修费 → 购买工具 → 解锁更难的案例。

章节专注一类设备，关卡逐渐增加故障范围、判断难度和拆装精度。新工具先解释原理与用法；旧工具出现在新结构上时，补充场景教学。例如气吹从电脑鳍片迁移到风扇护网，再到键帽间隙；二合一拔取器从拔键帽升级为释放轴体卡扣。

## 已实现

- 电脑首关已加入默认的 3D 手动操作：正反向螺丝旋拧、两个独立卡扣、沿轴拔出、自由对位、旋转方向、主动推入与侧板复装。对位本身不会安装，错位和错误朝向会阻挡插入。
- 第二关共用手动螺丝与侧板拆装；先在模型中长按固定叶片，再用气吹逐处短按清理六处积灰。持续吹气、点按过快和偏离目标不会清理。
- 第三关共用手动机箱拆装；辨认 15 针供电与 7 针数据接口，轻推检查供电，按住数据线金属锁扣并沿轴拔出，检查 L 形缺口，手动对位推入，最后轻拉确认固定。这条教学线材带锁扣，不将所有 SATA 数据线都描述为带锁扣。
- 第四关加入手动 USB 风扇清洁：逐颗旋松护网的四颗螺丝，沿轴拉脱定位柱，再移到旁边；固定叶片，分别清洁护网四处、叶片五处积灰，最后对孔、主动推回并旋紧螺丝。护网的拆出与装回都不会自动吸附。
- 第五关加入可维护含油轴承的手动维护：轻拨后观察快速停转，转到背面检修窗口，拔出并移开注油胶塞，少量点涂，手动对孔压回后再次轻拨比较。润滑前后使用相同的教学轻拨强度与不同阻力系数，形成可见的惯性差异；仅点油或仅密封都不能完成维修。
- 前七关手动模式中的机械步骤不能用“下一步”按钮完成；辅助教学是明确分开的可选入口。其余两关目前仍为辅助教学，尚未完成同等深度的手动拆装。
- 第六关加入万用表实际测点交互：先分离低压线组、短接表笔自检，再拖动两笔分别接触同一导体两端，形成正极断路与负极正常的对照证据。换线前收回表笔；新线保持两端分离复测，收回表笔后分别对位、主动推入两端并轻拉确认。悬空、同端或跨导体测量不记为整根导线的证据。
- 第六关四个持久步骤为分离旧线、诊断旧线、准备新线、复测与接回；最后一步明确先测量后连接，避免连接设备后测通断。逐根读数、自检、仪表档位和未完成的线材/表笔姿态仅在本次操作保留，刷新重做当前步骤，旧存档的已完成维修保留。
- 第七关加入普通单键维护：无需拆外壳，选钢丝拔键端，下套扣住两侧下沿，沿键盘法线提起，再移到零件盘。轴体留在定位板上；四处键下碎屑使用气吹短按清理。键帽必须对准固定十字轴，再主动压回；三次实际按下、松手并完整回弹后才完成机械维修，接回 USB 后另验输入。
- 第七关保留“取下键帽 / 清理碎屑 / 装回与回弹检查”三个持久步骤；未完成的内部姿态、局部碎屑和回弹次数刷新重做。兼容旧教学存档的外壳状态，在完成维修时恢复闭合；不把单键清洁教成必须拆整把键盘。
- 第五关沿用四个持久维修步骤的含义，维护结构明确为无需螺丝刀的手工注油胶塞；旧存档继续当前步骤。未完成的胶塞位移、惯性观察及最后一步中的密封姿态不跨刷新保存。
- 第四关保留原有的两个持久维修步骤：固定叶片、完成清洁。九处局部清灰、未完成的护网位移与螺丝旋拧是瞬时操作，刷新后重做当前步骤；旧存档的步骤含义保持一致。
- 第三关仍使用原有的两个持久维修步骤，兼容旧存档；锁扣按压、拔出、对位、推入与轻拉验收中的未完成姿态只在本次操作期间保留，刷新后重做当前步骤。
- 电脑、USB 风扇、机械键盘共 9 个可玩工单；三个设备的独立 3D 模型。
- 初始观察、螺丝刀、拆装；通过市场获得气吹、接线套件、润滑套装、万用表、拔取器与轴体套件。
- 工具所有权和操作前置条件检查；每次交付先通过设备验证与知识题。
- 首次发现零件的自动教学、按场景出现的工具教学、图鉴、笔记与维修日志。
- 章节和关卡依次解锁；维修费、经验、购置扣费、永久装备、重玩奖励去重与本机存档。
- 完整 12 类设备的可浏览章节地图；未实现内容明确标为“筹备中”。

## 经济设计

初始资金 ¥200；九张首通工单共提供 ¥1690；当前完整采购需要 ¥700，全部首通并采购后剩余 ¥1190。必要装备的购买价格与章节解锁时间经过预算测试，不会出现必须买工具但无可用资金的正常推进死局。

当前市场是“购买更专业的工具与替换套件”。套件永久保留、不重复消耗，避免早期原型被库存管理打断。后续可加入工具等级、精度、拆装效率和可选预算挑战，但不让付费或昂贵工具替代正确诊断。

## 后续应做的交互升级

1. 把已在前七关验证的手动交互扩展至其余工单和工具：FFC 插拔、释放卡扣拔轴、轴体通断与电路测试点。继续保留明确标注的辅助教学，不能把零件放到高亮位置就自动连接。
2. 工单逐渐减少提示：先跟做，再按症状选择检查路径，最终独立定位多故障。
3. 增加诊断仪实际界面、可检查测试点、可验证读数，避免仅凭任务按钮得到结论。
4. 增加零件兼容性、库存、返修与客户评价；用误诊与验证结果影响评分。
5. 新增手机和高风险章节前，先完成模型、设备规范与专业内容审校。真实市电、高压电容、锂电池、制冷剂、车辆安全和航空系统不直接照搬消费电子教程。

## 扩充一章的入口

在 `src/game.js` 添加设备零件、工单与工具条件；在 `src/tutorials.js` 添加场景教学；在 `src/Workbench.jsx` 添加设备模型及可点选分组；在 `src/roadmap.js` 将规划条目关联到实际可玩的 chapter id。用同一套维修状态机、市场与存档，不另建平行系统。
